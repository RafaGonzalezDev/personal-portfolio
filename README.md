# Personal Portfolio

A modern personal portfolio built with React and Vite, showcasing professional experience, featured projects and technical skills.

![Portfolio Preview](./public/portfolio.png)

## Features

- **Responsive Design**: Optimized for all devices
- **Smooth Animations**: AOS implementation for fluid transitions
- **Modular Architecture**: CSS Modules for maintainable code
- **Optimized Performance**: Built with Vite

## Tech Stack

- **Frontend**: React 19, JavaScript ES6+
- **Bundler**: Vite 6.2
- **Styling**: CSS Modules
- **Animations**: AOS (Animate On Scroll)
- **Linting**: ESLint

## Project Structure

```
src/
├── components/     # Reusable components
│   ├── Navbar.jsx
│   └── Separator.jsx
├── sections/       # Main portfolio sections
│   ├── Home.jsx
│   ├── Experience.jsx
│   ├── Projects.jsx
│   └── Contact.jsx
├── layouts/        # Main layout
│   └── MainLayout.jsx
├── styles/         # CSS Modules per component
├── assets/         # Static images and resources
├── constants/      # Configurations and data
└── utils/          # Utility functions
```

## Installation & Usage

### Prerequisites
- Node.js 20 or higher
- npm or yarn

### Installation

```bash
# Clone repository
git clone [repository-url]

# Navigate to directory
cd personal-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Available Scripts

```bash
npm run dev      # Development server
npm run build    # Production build
npm run preview  # Build preview
npm run lint     # Run ESLint
```
